Preuves : Rapport de tests, CI/Pipeline		 - Aucun test écrit ou exécuté

Compétence 2 : Sélectionner les algorithmes adéquats (Semestre 3 - Parcours A)

Apprentissage Critique Situation Non Acquise En Cours d’Acquisition Acquis
AC1 — Choisir les structures de données adaptées

Preuves : Analyse README, Code		 - Structures inadaptées au problème
- Données dupliquées ou mal organisées
- Choix par habitude sans réflexion		 - Structure cohérente mais choix non justifié
- Utilisation de structures avancées (Set, Map)
- Modification si problème rencontré		 - Comparaison avant choix

AC2 — Sélectionner les bons algorithmes

Preuves : Benchmarks, complexité		 - Résultats faux ou incomplets
- Algorithme ne correspond pas au problème

- Optimisations sans mesure concrète
- Utilisation d'algos de cours		 - Choix selon contraintes (temps, mémoire)
- Analyse complexité Big-O
- Améliorations pertinentes proposées
AC3 — Sécuriser les traitements algorithmiques

Preuves : Validation entrées, Logs		 - Données non vérifiées
- Programme exploitable ou instable
- Pas de gestion des entrées malveillantes		 - Filtrage partiel des données
- Gestion d’erreur partielle
- Données sensibles peu protégés		 - Vérification systématique des données
- Protection injections/débordements
- Traçabilité et gestion erreurs
AC4 — Réduire l’impact environnemental

Preuves : Profiling, Rapport éco-conception		 - Ressources ignorées
- Gaspillage CPU / mémoire
- Pas de réflexion sur l’impact		 - Quelques optimisations sans justification
- Impact évoqué après coup
- Améliorations ponctuelles		 - Optimisation dès la conception
- Solution économe en ressources
- Documentation des impacts réduits
