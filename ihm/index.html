Contrôle Roomba
par tablette

Application de télécommande IHM

Conception d'une interface graphique en Processing (Java) pour piloter un Roomba modifié. Chaque bouton de l'interface envoie un signal distinct à la carte Arduino via Bluetooth, qui transmet ensuite les ordres au Roomba. La vitesse des moteurs est réglable sur 5 niveaux via des rectangles au centre de l'interface. Deux dispositions sont proposées pour les droitiers et gauchers.

// Fonctionnalités
  • Boutons de commande directionnelle · chaque bouton envoie un signal distinct
  • 5 niveaux de vitesse moteur sélectionnables via 5 rectangles au centre de l'interface
  • Mode Droitier / Gaucher avec disposition miroir des boutons
  • Chaque action utilisateur déclenche l'envoi d'un signal Bluetooth vers l'Arduino
  • Interface pensée pour une utilisation simple et réactive
// Contexte technique
  • IHM développée avec Processing (Java)
  • Communication via Bluetooth entre l'IHM et la carte Arduino
  • L'Arduino reçoit les signaux et pilote directement le Roomba
  • Projet réalisé au lycée dans le cadre d'un cours IHM
  • Couplé au projet hardware Arduino → voir le labo
